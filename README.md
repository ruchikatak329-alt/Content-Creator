# Mansi Sankhla - Content Creator Portfolio

## Put it on Vercel (new project)
1. Create a NEW GitHub repo and upload everything in this folder (index.html, api/, package.json, vercel.json).
2. On vercel.com: Add New > Project > import that repo > Deploy.
3. In the project: Storage > Create > Blob > connect it to the project. This adds BLOB_READ_WRITE_TOKEN automatically.
4. Settings > Environment Variables > add ADMIN_PASSWORD = the password you want. Then Deployments > Redeploy.

## Editing (works like your old site)
- Open yoursite.vercel.app/admin and enter the password.
- Edit Site: click text to type, click a photo/video frame to upload from your device.
- Design: fonts and colours. Stickers: drop, drag, double-click to remove.
- Download Updated Site, then replace index.html in your repo with that file and let Vercel redeploy. Only then do edits show for everyone.

## Your cat stickers
Copy the two cat images from your old repo into this folder and name them cat1.png (About) and cat2.png (Why Me). Until then a drawn cat is shown.
